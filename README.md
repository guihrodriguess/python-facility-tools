# python-facility-tools

Ferramentas em Python para quem gerencia contratos de manutenção predial e facilities.

> Feito por um engenheiro eletricista que coordena contratos de manutenção predial, para resolver problemas reais da operação.

## Ferramentas

### [Radar de licitações](./radar_licitacoes)

Lista os pregões eletrônicos com proposta aberta no PNCP que são de manutenção predial, conservação e limpeza, com pontuação explicada e link para o edital. Só biblioteca padrão, sem chave e sem navegador.

```bash
cd radar_licitacoes
python radar.py --uf MG --dias 30
```

## Requisitos

Python 3.10 ou mais novo. Cada ferramenta lista no próprio README o que precisar além disso.
